# 树海 Reader ver 1.0 · 识别更新

启动便携版的 `TreeSeaReader.exe`，在 Reader 选定游戏窗口，开启实时跟读。在游戏中打开持有清单。Reader 显示本页卡片识别进度，翻页后可继续读取。

- 藏品按绿色卡片标题分区读取，低置信文字可由藏品图标辅助核对。
- 干员按名牌和等级分别读取。精英阶段、潜能和技能等级仍以明确可读的字段或手动录入为准。
- 零件清单显示当前估价、可用次数和箱内总估价。同一页的同名零件保留各自的卡片记录，选中该条目可查看各张卡片。横向边缘只露出名称时，翻到完整卡片再读估价和次数。
- 同层同构型的有效读取补充已揭示节点。低置信预览保留当前地图，已确认的节点类型沿用至地图切换。人物标记在两个位置之间变化后，主界面显示最近进入的节点。
- 进入事件后，Reader 对照 PRTS 插画和可读的事件标题。自动记录出现在「清单 → 事件」，同时从对应的本局事件池排除已遇的一次性事件。节点与事件行动随本局存档保存。
- 流窜居民优先在节点右上角识别。出生点观察到的居民用于筛选五步内的据点候选，候选显示在节点下方。

样图覆盖两张藏品页、一张干员页和一张零件页。零件中可见 10 张卡片，8 张露出估价，7 张显示移动次数。事件插画使用合成画面和非事件画面验证，真实事件界面与更多清单滚动位置仍待实机验证。
