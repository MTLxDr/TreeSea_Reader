# 实时跟踪与探索查询

版本：2026-11-01，r4。

## 实时跟踪

1. 打开游戏窗口，在 Reader 左侧刷新窗口列表，选中游戏窗口，点击“开始实时跟踪”。
2. 在游戏中打开地图、已有藏品、零件箱或已招募干员页面。程序每秒检查一次，两次一致的识别结果才更新本局。翻页后继续同步可见条目。
3. 地图出现近似构型时，在右侧确认构型。人工锁定的节点和清单字段保留，低置信度字段不会覆盖旧值。
4. 开始另一局先点“新建本局”。程序清除上一局实时观察缓存，重新读取当前画面。点击“停止实时跟踪”结束采集。

采集绑定所选窗口，优先使用 Windows Graphics Capture；启动失败时使用窗口截图。实时路径保留当前页签，不唤起、不切换前台、不逐帧保存图片。手动截图仍按“读取完成后显示结果”设置请求前台一次。窗口最小化时等待恢复；窗口关闭或被替换时重新选择窗口。

## 位置、居民与概率

人物标记优先定位；未找到人物、构型已确认且恰好只有一个完全未匹配节点时，按用户确认规则将该点视为当前位置。位于出生点时，视作本层开始，记录当时可见的初始居民。

初始居民位置确定为原始林间空地；居民据点候选须同时位于所有已记录初始居民的实际连通路径5步以内。这里使用地图连线，不使用直线距离。

居民占领与底层节点分开保存。居民当前或曾经进入的位置，排除诡意行商、秘境行商、险路小径、险路尽头、曲折密道、命运所指和居民据点。居民移走后记录仍保留，保存/重载和后续同图识别均有效；换图或新建本局时清除。底层完全未识别时，候选包括原始林间空地和羽瞰点，按源距离计数估算；已确定的初始空地计入本层数量，重复识别命中缓存时保持该结论。

同图以楼层、构型、节点格点、连线、起点及出口一致判定。居民记录变化使概率缓存失效；节点概率继续使用路标距离频数和本层数量范围。主图标出有正概率的秘境行商、误入奇境位置。第1、2、4层构型确认后的固定出口继续直接标注。

四结局右侧熄日余径独立匹配，不纳入主图构型和主图数量统计。

机制来源：[PRTS：沉沦者的黑流树海，流窜居民](https://prts.wiki/w/沉沦者的黑流树海)。出生点和唯一未匹配节点判定为用户确认的项目规则。

## 事件池、藏品池和关卡

地图右侧显示本层不期而遇池。自动读到事件标题时记录，也可手动选择后记录；已遇非重复事件移除，可重复事件保留。路标当前没有提供事件遭遇频数，因此明确显示“按路标池成员等权估算”。树洞选择入口楼层后显示该楼层参考池，不作为树洞专属权重。

顶部“藏品池”按版本、分类和名称查询剩余藏品/零件。快照含72个池，版本标识dlc1；按本局已确认且未移除的库存扣除，不推断未读取的个人解锁状态。

“关卡地图”页独立查询184个关卡及条件变体，含普通/紧急和内容扩展变体，不等于184张独立地图。勾选“额外猎犬proto”筛选猎犬，选择条件组和表格行查看相应路线；探险者用金色标记，底部显示坐标与激活条件组。“在PRTS.Map查看”打开源页面。

出怪时机从对应波次片段或触发分支起算，片段前置延时另列；不将清怪等待写成固定开场秒数。路线默认按通行地块静态寻路估算，可取消勾选以查看源移动点连线；传送段单独显示紫色虚线。
