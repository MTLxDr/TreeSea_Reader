# 树海 Reader

面向“沉沦者的黑流树海”的本地辅助程序。已具备资料数据库、Windows 截图与热键桌面程序，以及地图/资源识别、静默实时跟踪、居民约束、事件池与藏品池、独立关卡查询。

数据采集脚本使用 Python 标准库；桌面程序使用 PySide6、OpenCV 和本地 RapidOCR。新增 OCR 依赖安装在 `.venv`，原“大肥鱼”资料保持只读。截图不上传到 OCR 服务。

## 统一启动与便携版

双击 `TreeSeaReader.exe` 进入统一主界面；原四个中文CMD已修复并保留。命令行或Agent使用 `TreeSeaReaderCLI.exe`，支持calculate、api、recognize、update与自检。

便携版目录在 `dist/TreeSea Reader 便携版`，当前压缩包为 `dist/TreeSeaReader-ver1.0-win64.zip`。完整解压后运行EXE，Python运行环境、Qt、OCR模型、公开数据库与来源已包含；原本局存档和截图未打入包中。入口修复、日志和构建方式见 [启动与封装说明](docs/packaging.md)。

设置中的“TAB操作”可选择“长按显示”或“按键切换”，选择会保存，默认长按。Reader 前台地图页中，长按方式按住超过一秒开启、松开停止；切换方式按一次立即开启，松开后继续，再按一次停止。两种方式均先诡秘后凶戾、每种停留两秒，停止后常亮保留当前类型三秒。预测位置显示具体图标、名称和概率；失焦、最小化或离开地图页立即清除。相同楼层、构型及网格结构的连续识别合并为同一张地图，保留可靠识别及人工修正；概率输入不变时复用结果，节点或统计变化时重算。从更高楼层连续两次确认一层出生点后自动新建本局；单次异常层数保留原记录。一层内相同构型重开可点击“新建本局”。

## 实时跟踪与探索查询

顶栏选择游戏窗口后开启“实时跟踪”；地图、已有藏品、零件箱与已招募干员的可见状态会自动保存，翻页后继续读取。实时更新保留焦点和当前页签。居民移动后的节点排除记录持续保留；出生点初始居民按实际连线5步筛选据点候选。

清单新增“事件”，与地图旁事件记录统一，支持增删和撤销；候选按当层优先，其他楼层灰色列出并标注可遇楼层。地图旁可查本层不期而遇池，左侧“藏品池”可查剩余成员，“关卡”可独立查询出怪、proto路线和探险者坐标。事件池目前为明确标注的等权估算；184条关卡包含条件变体。操作、来源更新及具体缺口见 [实时跟踪与探索查询](docs/live_exploration.md)。

## 效果统计与独立数值计算

双击“启动效果库.cmd”可查询当前来源的21,160条分档记录，包含藏品、零件、分队、主题机制、难度、干员各级技能/天赋/潜能/模组、敌人及关卡规则。PRTS主目录仍为251件藏品、44件零件；来源和档位记录不能累加当作不同物品数量。

原文覆盖、来源运算标注与可执行状态分开。当前不是所有效果都已规则化；23个内部敌人变体没有独立PRTS页面，原始关卡数据保留，机制关联待核对。覆盖清单在 `reports/effect_coverage.json`。

双击“启动数值计算器.cmd”打开独立窗口，可录入关卡符文、藏品符文、四类属性修饰和伤害参数，查看每一步中间值并导出输入/结果/Schema。Reader左侧也提供“效果库”“计算器”入口。

默认“本局伤害计算”页读取已确认清单，选择干员和技能后输出0防0抗DPH与技能期间平均DPS。旧按关卡/敌人计算保留在高级页。缺项在结果旁列出；规则与来源约定见 [本局接入说明](docs/effect_rule_compiler.md)，操作及攻击时序见 [DPH与DPS说明](docs/session_dps.md)。

Python、JSON命令行及本机HTTP接口使用相同核心，支持伤害演算和单属性演算。运行“启动数值接口.cmd”后可访问 `http://127.0.0.1:8765`，或在独立计算窗口中启动/停止接口。

算法已统一按PRTS更新为 `0.3-prts`（接口 `1.2`）。白值与伤害增益分开；每一步提供算式与贡献来源，窗口支持数字悬浮查看和来源编辑。最终倍率默认逐项乘，同组相加/取最高等以具体机制为准；旧版显式请求保留兼容提示。不会自动套用未编译效果。流程见 `docs/calculation_algorithm_review.md`，接口说明见 `docs/calculation_api.md`，Schema见 `docs/calculation.schema.json`。交接执行Prompt见 `docs/agent_calculation_handoff_prompt.md`。

## 启动截图程序

双击 `启动树海Reader.cmd`，或运行：

```powershell
.\.venv\Scripts\python.exe -m reader.app
```

默认热键可在程序中修改：

| 热键 | 功能 |
|---|---|
| Ctrl+Alt+S | 截取前台窗口，识别后显示结果 |
| Ctrl+Alt+V | 显示或隐藏结果窗口 |
| Ctrl+Alt+Z | 撤销最近一次识别或修正 |
| Ctrl+Alt+1 | 按已有藏品页面识别 |
| Ctrl+Alt+2 | 按零件箱页面识别 |
| Ctrl+Alt+3 | 按已招募干员页面识别 |

如果热键被其他软件占用，状态线会提示，界面按钮仍可使用。重复启动会唤起已有实例。

设置中默认勾选“读取完成后显示结果”；启用时，完成读取后恢复窗口并请求前台一次，不持续置顶。置顶选项已移除，旧设置中的置顶开关不再生效；计算器和效果库也使用普通窗口。截图使用指定窗口句柄，Reader 遮挡目标时也可读取，不需要隐藏 Reader。更新后先关闭旧 Reader，再启动新版。

首次使用可先“导入图片”，也支持 Ctrl+V 粘贴截图。切到游戏地图后按识别热键，或使用“3秒后截取前台窗口”。单次、热键和实时截图统一使用 Windows Graphics Capture，顶栏选择窗口后始终针对该窗口采集。最小化时等待游戏恢复。

地图可缩放、平移并点击节点查看经验概率；右侧允许选择类型并手动锁定。资源数值可双击修正。手动修正在同一楼层/模板的后续截图中保留，新建本局可清空，并可撤销恢复。模板证据不足时先显示候选，不覆盖原地图。

## 查看节点概率

点击左侧“概率”入口，可直接查看“节点类型概率”“节点距离分布”“本层数量限制”。主图中点击未知的凶戾/诡秘，也会联动右侧概率和本局已确认数量；右侧按钮“查看完整概率与距离分布”可打开完整页。

基础估计使用路标 `N(楼层,距离,类型)` 计数，在对应未知类别中归一化。距离分布则按同一种节点在本层的各距离计数归一化，两者分母不同。百分比显示约整到1%，采用总和保持为100的分配方法，原始计数及精确值不修改。

已确认地图会按本层各类型的剩余名额，对节点距离频率构成的联合模型条件化；达到上限的类型归零。较小组合精确枚举，较大组合使用固定随机种子的有界抽样，并显示有效样本信息。上下限来自路标观测范围，属于经验约束，不表示已经还原游戏随机生成器。主图与余径独立计数，起点和低置信度小圆点不算作已确认空地；存在未确认格点时不强加数量下限。数据冲突或有效样本不足时显示待核对。

第1、2、4层构型确认后，模板中固定的出口直接标注“险路尽头 · 固定”；不要求OCR再次读出其标签。模板尚未确认时不作确定标注。

图像文字识别、地图几何推断和人工修正分别保存来源。地图页读取层数、生命/护盾、行动力、藏品数量、源石锭与零件数量/容量。藏品、零件和干员的文字识别已接入同一截图入口，结果在“藏品 / 零件 / 干员”页签中显示。

## 藏品、零件与干员

1. 打开游戏中的**已拥有库存 / 已招募干员**页面，按对应热键，或在左侧指定页面类型后截图。自动模式根据页面标题分流，判断不出时可以手动指定。
2. 核对本页候选名称、数量和练度；有近似名称或同名形态时默认不勾选。点击“确认选中条目并合并本页”。商店或招募选项中出现的名称不能直接视为已拥有。
3. 在游戏中人工翻页，再次截图合并。重复和重叠截图按条目 ID 更新，不累加数量；尚未扫描到的条目不会被删除。数量未读到时显示未知。
4. 本局表格可双击修改数值，也可使用“补录 / 修正”搜索名称。手动修正锁定保留，手动移除不会被下一张截图恢复；可撤销。确认所有页面后再勾选“已扫描全部页面”。

当前按可见名称匹配目录，支持读取附近明确写出的数量、LV 等级、精英阶段、潜能和技能等级；专精记录同时保留技能编号是否已知。图形精英标记、只有头像/藏品图标而无名称的界面、被遮挡名称暂不能保证识别，可通过详情页或人工补录辅助。阿米娅的不同职业形态保留为独立候选。当前未自动点击或翻页。

干员页的“技能 / 天赋 / 模组资料”按钮可查询444名干员的完整来源参数：技能1–7级和各档专精、天赋与潜能/模组变体、逐潜效果、模组各级和基础面板/信赖。原始嵌套模板及机制备注保留，格式化文字只用于阅读。已逐页联网刷新并记录PRTS修订号；历史本地原文也保留。没有提升潜能的干员会保留对应原文说明。

“补录 / 修正”中可以记录信赖、模组类型/等级和三个技能各自的专精。取得参数资料不等同于已经实现全部天赋/技能的伤害规则，后续计算仍需按练度选择适用变体并核对机制。

库存与地图独立保存于本局存档，支持撤销、新建本局和整体 JSON 导出。合成页面测试通过只说明文字识别与合并流程可运行，尚不代表三类真实游戏页面的识别准确率。

.\.venv\Scripts\python.exe -m pip install -r requirements.txt

批量识别与回归：

## 当前可用数据

- 路标：实际联网读取 21 个 JSON，另保存公开前端模块以提取模板。
- 地图几何：54 个模板，包含节点格点、连线、起点、出口及已有固定节点。
- 独立右侧熄日余径：12 个 3×3 模板，三/四/五层分别为 3/4/5 个，单独入库。
- 观测统计：节点距离计数、地图构造频次及样本量。
- PRTS：10 个核心页面的原文、修订号、页面更新时间及采集时间。
- 当前主目录：251 件藏品、44 件零件，效果保留为原文参数。
- PRTS 干员目录：434 个常规条目及 10 个集成战略专属条目；带来源 ID、原始属性和 HTML 校验值。
- 路标关卡资料：105 个关卡索引和对应详细配置；关卡内敌人记录按关卡、等级分别保存。
- 本体与 DLC 的池子和收藏品分区分别保留，未明示游戏版本的资源标记为未知，不按抓取日期推断版本。

数据库位于 `data/reader.sqlite3`，来源及历史快照在 `data/sources/`。

## 使用

```powershell
# 从项目已有来源清单重建派生表，保留历史来源修订
python scripts/database.py build
python scripts/database.py status

# 按原始观测计数归一化：二层、距起点三步，仅比较这两类
python scripts/database.py probability --floor 2 --distance 3 --types 作战 紧急作战

# 只检查是否到了更新间隔，不联网
python scripts/update_data.py --check-only

# 默认超过24小时才更新；显式强制刷新
python scripts/update_data.py --force

# 独立更新来源
python scripts/collect_lubiao.py
python scripts/collect_prts.py --online
python scripts/collect_operators.py
python scripts/collect_side_maps.py
python scripts/collect_node_limits.py
python scripts/collect_operator_details.py --online

# 验证
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
python scripts/collect_prts.py --self-check
```

`update_data.py` 是供后续桌面程序启动、更新按钮或热键调用的入口；当前未创建系统定时任务。

## 数据使用约定

`documents` 保存来源内容修订，`source_observations` 保存每次获取的证据；`active_documents` 选择当前使用的修订。相同内容复用，累计统计快照不会跨次相加。原始 JSON 和页面源码均保留。

`current_prts_catalog` 是程序应使用的当前主目录视图；`entities` 中还包含历史转存、分版本记录和其他页面的重复展示，不能简单按整张表计数作为藏品总数。藏品效果仍是来源文本，尚未转化为经过核对的数值计算规则。

`active_map_templates` 给出当前模板几何。模板频次与模板定义分开保存；第四层追忆有自己的统计分组，可引用第四层几何，不能当成新增10张几何图。

基础概率按所选观测集合中的 `N(楼层,距离,类型)` 归一化。未观测到不证明不可能；尚未取得的模板、标记、揭露状态联合统计不会被臆造。后续取得更多观测后可以增加条件维度。

## 地图识别与热键方向

使用本地 OCR 识别地图标签和资源数字，拟合规则格点，再以出口、已观测节点及局部连接证据匹配已有构造模板。用户提供的二层截图已自动匹配为 F2-T05（19节点、20边）；主动截取的一层实际游戏画面自动匹配为 F1-T01（11节点、11边）。这些结果不能代表所有54种构造都已实测。

F2-T04 与 F2-T05 具有相同节点占位，因此节点位置还需结合起点、出口或少量关键连线确认。低对比度线条作为局部证据，不单独承担全图恢复。若多个模板仍然相容，保留候选并允许纠错。

左下角减号按钮可在游戏中缩小地图。Reader 读取“＋/－”状态并给出提示；检测到加号也不能证明边缘未截断。主图格点尺寸从模板读取，已取消旧的最多8列限制，支持后期10列构造。

三至五层按主图与右侧小图分别匹配，界面有独立小图页签和模板候选。可手动指定小图存在/不存在后重读。小图坐标、节点修正与主图分开，不添加未经证实的跨图连线，也不套用主图距起点概率。未分离出小图不等于小图不存在；尚缺真实右侧小图截图验证。

部分小圆点仍只标为候选空地；人物遮挡处可以保留为未识别。当前人物位置尚未独立识别，模板起点不会被冒充成当前所在位置。

## 效果库与独立数值计算

- 双击 `启动数值计算器.cmd` 打开独立窗口，可录入各属性乘区、计算并查看中间过程，导出请求、结果与 JSON Schema。

- 双击 `启动数值接口.cmd` 启动 `127.0.0.1:8765` 本机接口。可视化窗口也有接口启停按钮；Python 与 JSON 命令行可独立调用。
